Native GF1-compatible Gravis UltraSound music and sound-effects support for the
supported DOS release of *Aladdin*.

Download `aladdin-gus-1.1.zip`, extract it into the installed game directory,
make sure `ULTRASND` contains the card's actual resources, and run `INSTALL`.
The archive includes the DOS installer, configurator, restore utility,
installation README, license, and checksums. It contains no source tree, game
executable, or game assets.

The original game still requires at least 1 MB XMS and 1 MB EMS.
